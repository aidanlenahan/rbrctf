# README
This directory aims to replicate CTFd as closely as possible, but where GitHub Pages is able to host it as a static set of files.<br><br>
Instead of a dynamic site checking for user submission of flags and updating of a scoreboard, this is delegated to a Google Form, where responses are limited to one per user and allows users to edit their responses later, serving as an answer checker. This Google Form is connected to a Google Sheet, which is embedded into the site and sorted by score, serving as a Github Pages-friendly scoreboard.
